ChatConfiguration

public struct ChatConfiguration

ChatConfiguration holds additional configuration parameters that are passed to the UI module wrapping the SDK.

Properties

  • additionalCustomerCustomFields

    Additional custom fields for the customer.

    These fields are used to privde extra information about the customer.

    Note

    Can be used to provide additional custom field(s) to the chat.

    Important

    Additional custom field(s) must be defined in the channel configuration. Otherwise, the custom field(s) can cause the chat initialization to fail.
