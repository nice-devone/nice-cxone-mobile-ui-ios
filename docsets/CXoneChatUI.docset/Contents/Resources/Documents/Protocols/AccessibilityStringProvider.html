AccessibilityStringProvider

public protocol AccessibilityStringProvider

A protocol for providing custom accessibility strings to the CXoneChatUI SDK.

Implement this protocol to programmatically override individual accessibility strings without replacing the entire Accessibility.strings file. Return nil for any key you do not want to override — the SDK will fall back to its own default.

String keys match the keys in Accessibility.strings (e.g. "message_input.button_send.hint_enabled").

Note

Parameterized strings (e.g. "Agent %1$@ has joined the conversation") must use the same %1$@ positional format as the SDK’s own strings.

Example

class MyA11yProvider: AccessibilityStringProvider {

    func accessibilityString(forKey key: String) -> String? {
        switch key {
        case "form.button_confirm.valid.hint":
            return "Double-tap to submit"
        default:
            return nil
        }
    }
}
