Protocols

The following protocols are available globally.

  • AccessibilityStringProvider

    A protocol for providing custom accessibility strings to the CXoneChatUI SDK.

    Implement this protocol to programmatically override individual accessibility strings without replacing the entire Accessibility.strings file. Return nil for any key you do not want to override — the SDK will fall back to its own default.

    String keys match the keys in Accessibility.strings (e.g. "message_input.button_send.hint_enabled").

    Note

    Parameterized strings (e.g. "Agent %1$@ has joined the conversation") must use the same %1$@ positional format as the SDK’s own strings.

    Example

    class MyA11yProvider: AccessibilityStringProvider {

    func accessibilityString(forKey key: String) -> String? {
        switch key {
        case "form.button_confirm.valid.hint":
            return "Double-tap to submit"
        default:
            return nil
        }
    }
}

  • LocalizationStringProvider

    A protocol for providing custom localization strings to the CXoneChatUI SDK.

    Implement this protocol to programmatically override individual strings without creating or modifying a CXOneChatUI.strings file. Return nil for any key you do not want to override — the SDK will fall back to the bundle lookup and then to its own built-in default.

    String keys match the keys in CXOneChatUI.strings (e.g. "common.confirm").

    Note

    This is the programmatic counterpart to the bundle-based approach. Use it for a small number of targeted overrides or for dynamic runtime resolution. For full language support, the bundle-based approach with .lproj files is recommended.

    Example

    class MyLocalizationProvider: LocalizationStringProvider {
    func localizationString(forKey key: String) -> String? {
        switch key {
        case "common.confirm":
            return "Done"
        case "common.close_chat":
            return "End chat"
        default:
            return nil
        }
    }
}
